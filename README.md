# ESP32 Smart Energy Monitoring System

An IoT-based smart energy meter using ESP32 for real-time voltage, current, and power monitoring with AWS IoT cloud integration.

---

## Features

- Real-time energy monitoring
- UART serial communication
- AWS IoT cloud connectivity
- ESP32 firmware development
- Live sensor data transmission
- Power consumption tracking

---

## Technologies Used

- ESP32
- Embedded C
- UART Communication
- AWS IoT Core
- IoT Sensors

---

## System Architecture

ESP32 → Sensor Module → UART Display → AWS IoT Cloud

---

## Project Objective

The objective of this project is to monitor electrical power consumption in real time and upload the data to cloud services for remote monitoring and analysis.
